**Redeye — mode 6.** The picker stops at *Bypass permissions*, which only takes the prompts away: it does not stop you asking in prose, and it does not stop you stopping. Redeye is that mode plus both of those. Local or cloud, any agent (Claude Code, Cursor, Codex, chat). On when Pato says `redeye`, off when he says stop — finishing something does not turn it off.

Boot: `deno task redeye` (prompts off, write gate on, this card) · `deno task boot` (where you are, the fleet, every live claim) · Rules §0, then the domain's Docs page before you write it (I-8).

## Asking is prohibited

Nobody is awake. A question is not caution here, it is the rest of the night. Every question you would ask, you answer yourself:

- **Reversible** — naming, layout, copy, file placement, either of two green designs: decide, comment `decision: <what> — <why>`, ship. Pato reverts what he dislikes in a minute; he cannot get the night back.
- **Ambiguous scope** — take the narrower reading, ship it, file the wider one as its own issue.
- **Genuinely blocked, and only these three (I-7)** — a secret you do not hold, money that moves for real, a Rules change. Label `needs-human`, comment what you need in one line, leave the issue, **take the next one**.
- Never write "should I", "would you like", "confirm", "let me know". Never end a turn on a question mark. A turn that ends without a next action is a stall.

## Never stop

The unit of work is the QUEUE, not the issue. A merge does not finish you; it puts you between issues.

1. `deno task boot` — take the top unblocked issue whose footprint is disjoint from every live claim.
2. `deno task worktree add MESITA-<id> <slug>` (a cloud clone: `--adopt .`) · In Progress · paste the claim line.
3. Read the domain's Docs page. Small commits. Push early.
4. `deno task worktree pr` → `gh pr ready` → checks → `gh pr merge --squash`. Healthy is UNSTABLE, not green; a path-filtered check reporting SKIPPED is mergeable.
5. Rewrite the Docs page. Close the issue. `deno task worktree remove`.
6. Back to 1, in the same breath. Announcing the loop is not running it.

Red CI is yours to fix, not to report. A review comment is yours to answer in code. Stop only when Pato stops you, or when the queue holds nothing you may claim — say that in one line and stop.

## What the bypass does not buy

The prompts are gone; the law is not. `preflight.sh` still refuses every write outside a claimed workspace, and the pre-commit hook still refuses the commit — the prompt was never the lock, the claim is (I-3, I-6). Never `--no-verify`. Never push to `main`. Never write in the shared checkout (I-4). Every repo, Notion or cloud write still has an issue (I-1).
