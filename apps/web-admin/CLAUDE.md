# apps/web-admin — internal admin console

> Read root [`CLAUDE.md`](../../CLAUDE.md) first; Notion holds the deep docs. Package rules only below.

- Light theme + semantic tokens. Map: Notion Docs › Design. New UI takes chrome from [`src/components/admin-ui/`](./src/components/admin-ui/), never a route-local shim. `/brand` is read-only, unlisted.
- Clients never touch the DB — all via `admin-web-*` EFs. EF-invoke is the **`Result` variant** (consumer/business throw `EFError`).
- Every config page: server seeds → client form → **WHOLE-BLOB save** to one `app_config` column, normalizer in lockstep, `dirty` gated on `loadError`. A knob nothing reads is **STAGED**.
- **A label never repeats its section heading** — Configurations › **Intake**. Labels live in `nav.ts`; routes, blobs, EF names never follow. Sidebar: `CONFIGURATIONS_NAV`. **Intake** = Intaker (Create **1–5**, Enrich **1–10**; 10 = Embedding). One box: Create · Delete · List · Unlist · Enrich. Delete archives, reversible only by hand. Active/Verified/Partnered write from web-business (claim → verify → own → Stripe) — never admin. Admin states: General · Partnership · Intake. Search eligibility: Discovery › Map; Places: one query/line. **Verification** = place ownership; **Ojo** = guest screenshot. Memo powers Discovery chat; Chat writes `discovery_config.chat.prompt`.
- **Discovery** (`/filters-config`): nouns are **Mode** · **Source**. Three subpages: **Matrix** (`/matrix`, matrix + Signals; the index) · **Modes** (`/modes`): Word · Map · Catalog · Swipe · Chat · Favorites. Word is one mode, two passes; alone it returns Locations. **Sources** (`/sources`): nine: 3 Google · 4 Mesita Places · 2 Mesita Social (last four Soon). Perplexity is no Source. Signals: eight in `_shared/discovery-signals.ts` (§8.3 order); `semantic` → Summary. Slice Save. Floor inside each box; types strip is a header, not a box. One owner per key, rest mirror: Autocomplete `general`, Nearby `map` floors, Mesita Nearby `filters` (also Home rails, Pay, bbox, Swipe). Soon gets no field. `requireReady`/`maxDistanceKm` unknobbed.
- **Visits** (`/visits-config`): Bill · Sync · Report (`visits_config`) plus **Ojo** (`ojo_config`, own Save). Unwired keys stay in that blob, off the HTML. **Orders Config** = the REMOTE context. Neither prices — rates are Rewards. **Credits** (`/controls-config`, `controls_config`): box **Terms** — the Wallet's hold (**3h**) + bonus + expiry, FALLBACKS a place may override, capped. Gifting Soon. Premium clamps up to the Free quota; the preselected tip must be a chip that exists.
- **Rewards** (`/rewards-config`, blob `promos_config`, **one page**) edits VISIT COMPONENTS only. Three super boxes: **Strategies · Discount Cap · Expected Distribution**. One Save; `/tiers` `/distribution` redirect. Twin: `web-business/lib/business/promos.ts`. **The per-place editor is NOT in this console** — it lives in `web-business` (`/places/[id]`); admin manages places in BULK only (`/manage-multiple`, label **Places**). **"promo"/"membership" BANNED in copy.**
- `database.types.ts` is hand-copied across web apps — regenerate from cloud, never hand-edit. CI `web-admin.yml`: lint · typecheck · build, Node 22+, path-filtered.
