# apps/web-admin — internal admin console

> Read root [`CLAUDE.md`](../../CLAUDE.md) first; Notion holds the deep docs. Package rules only below.

- Light theme + semantic tokens. Design map: Notion Docs › Design. New UI takes chrome from [`src/components/admin-ui/`](./src/components/admin-ui/), never a route-local shim. `/brand` is read-only, out of the sidebar.
- Clients never touch the DB — everything via `admin-web-*` Edge Functions. The EF-invoke wrapper is the deliberate **`Result` variant** (consumer/business throw `EFError`) — keep it.
- Every config page: server seeds → client form → **WHOLE-BLOB save** to one `app_config` column, normalizer in lockstep, `dirty` gated on `loadError`. A knob nothing reads is **STAGED**.
- **A label never repeats its section heading** — Configurations › **Intake**, never "Intaker Config". Labels live in `nav.ts`; routes, blobs, EF names never follow. Sidebar = `CONFIGURATIONS_NAV`. **Intake** = Intaker (Create **1–4** / Enrich **1–10**). **Status**: seven bools + Promoted 0|1|2; Intake 0. Seed … 10. Semantic. Search eligibility is Discovery › Map (`discovery_config.map`); Multiple Places Search is one query per line (results floor 1) and does not re-author floors — named IDs consume Map too. Single Place name search is Discovery Deep; empty query lists Mesita. `/sourcing-config` redirects to `/filters-config`. No Atlas page (Docs › Atlas). **Verification** = place ownership; **Ojo** = guest screenshot. Memo is Discovery's chat engine; Chat writes `discovery_config.chat.prompt` (blank = in-code persona).
- **Discovery** (`/filters-config`): boxes General · Name · Map · Swipe · Catalog · Chat · Social · Favs. General LIVE (`discovery_config.general.categoryCount`, first N Google types). Fast Search + Deep Search stay two boxes (`discovery_config.name`). Map LIVE (three closest-N lanes). Swipe LIVE (`discovery_config.swipe` — hard filters, proximity+popularity sum, partner bias, random multiplier; `consumer-web-recommend-swipe`). Catalog Soon (empty box; blob stays). Social Soon (empty box; blob stays). Chat prompt LIVE. Favs live on Home, no knobs. Signals Soon. Slice Save. Slotting/filters persist, **no knobs**.
- **Visits** (`/visits-config`): Bill · Sync · Report (`visits_config`) plus **Ojo** (`ojo_config`, own Save). Unwired visits keys stay in that blob, off the HTML. **Orders Config** = the REMOTE context. Neither prices anything — rates are Promos. Premium clamps up to the Free quota; the preselected tip must be a chip that exists.
- **Promos Config** (`/rewards-config`, **one page**) edits VISIT COMPONENTS only. Three super boxes: **Strategies · Discount Cap · Expected Distribution** (Calculator last inside Distribution). One Save. No Tiers/Distribution tabs. `/tiers` `/distribution` redirect. Twin: `web-business/lib/business/promos.ts`. **Single Place › Promos** is three boxes: Tutorial · Partnership · Promos (Zero · Conservative · Aggressive; Give/Placement = Low · Mid · High). Performance stays Soon.
- `database.types.ts` is hand-copied across the web apps — regenerate from cloud, never hand-edit. CI `web-admin.yml`: lint · typecheck · build, Node 22+, path-filtered.
