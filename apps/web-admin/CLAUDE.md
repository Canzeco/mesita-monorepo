# apps/web-admin — internal admin console

> Read root [`CLAUDE.md`](../../CLAUDE.md) first; Notion holds the deep docs. Package rules only below.

- Light theme + semantic tokens. Map: Notion Docs › Design. New UI takes chrome from [`src/components/admin-ui/`](./src/components/admin-ui/), never a route-local shim. `/brand` is unlisted.
- Clients never touch the DB — all via `admin-web-*` EFs. EF-invoke is the **`Result` variant**.
- Every config page: server seeds → client form → **WHOLE-BLOB save** to one `app_config` column, normalizer in lockstep, `dirty` gated on `loadError`. A knob nothing reads is **STAGED**.
- **A label never repeats its section heading** — Configurations › **Creation**. Labels live in `nav.ts`; routes, blobs, EF names never follow. Sidebar: `CONFIGURATIONS_NAV` = Models · Atlas · Creation · Enrichment · Discovery · Reservations. Multiple Places writes in three boxes, **Create · Enrich · Edit** (List · Unlist · Delete; never an Edit button) — buttons repeat box names, except Enrich's Weak and Strong. **"Crenup" BANNED.** Enricher: Create 0·1·7·8, Enrich **1–8**. Delete archives, reversible only by hand. **Creation** holds the two Create-on-open switches (consumer app · admin app): opening a Google-only result's full profile is the one thing that mints a place; an explicit Create is never gated. **No verification, partnership, rewards or payments** (MVP). Search eligibility: Discovery › Area; Places: one query/line. **Ojo** = guest screenshot. Discovery › Deep writes the Chat prompt (`discovery_config.chat.prompt`). **Models** (`/models-config`) = four AI jobs: Memo's `models_config` model + Enricher writing/photos/search (`enrichment_config`); Creation links there.
- **Discovery** (`/filters-config`): ONE page, no subpages. Four boxes, one per pipeline as run: **Name Pipeline by Admin** · **Name Pipeline** · **Area Pipeline** · **Deep Pipeline**. Each is a `PipelineBox` (Explanation · Sources · Signals · Gates · Scoring · Parameters · Save) drawn from `discovery-surface.ts`, saving only its own slices; a source nothing retrieves shows **Not wired**. Area is a weighted sum (Proximity × its weight + Popularity × its weight, `params.balance`) with a cap per scope (`map.googlePlaces` bought · `map.mesitaPlaces` read); Map and Feed are its views. Floors stay in the box that owns them; family membership lives on Atlas.
- **MVP First Stage rail:** Account · Manage · Configurations · Testing (**Billing** `/billing-test` · **Logs** `/logs`). Alerts and every Second Stage page (Visits, Rewards, Ojo, Orders, Payments, Diamond) are deleted, routes and config sections. Manage: **Multiple Places** (`/manage-multiple`, bulk) · **Single Place** (`/manage-single`: Find, then `/[id]/{profile,reviews,preview,admin}` — `FIRST_STAGE_TABS` in `[id]/access.ts`; Reviews reloads Google, Instagram and Facebook and is not part of Enrich; Preview renders the saved place through `packages/place-profile`, the consumer place screen's module). **"promo"/"membership" BANNED.**
- `database.types.ts` is hand-copied across web apps — regenerate from cloud, never hand-edit. CI `web-admin.yml`: lint · typecheck · test · build, path-filtered.
