The Inbox tab is a real container with **four sections in a fixed order** (2026-08-16): **Visits · Orders · Reservations · Notifications** — `/inbox/{visits,orders,reservations,notifications}`, bare `/inbox` → visits. **The order is load-bearing**: it runs from what you're doing RIGHT NOW out to the passive feed; a pinned test asserts it, since `toEqual` would let an alphabetical re-sort through.
