# apps/web-consumer — consumer app (consumer.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first — the quickstart; Notion holds the deep docs. Package-specific rules only below.

- **Light theme + semantic tokens only** (`bg-card`/`text-foreground`/`border-border`), never `bg-zinc-900`/`text-white` — TWO carve-outs, bounded there: `BalanceCard`'s photo face, `CreditsClient`'s border-less rows. Surfaces read **premium**; wireframe stacks = regression. Map: Notion Docs › Design.
- **Overlay & loading primitives are mandatory:** route modals = `SlideOverShell`/`BottomSheetShell` from the segment `layout.tsx`, never `page.tsx`; state overlays = `LocalSheet`/`LocalDialog`, never `fixed inset-0`; loading = `Spinner`/`Skeleton`. **ONE semi-modal: `SEMI_MODAL_PANEL_CLASS` (80%) on BOTH sheet shells** — never hardcode a panel height. **A confirm is a `LocalDialog`, not a short sheet.** Z: BottomNav 40 · @modal 120 · local 130 · Toaster 140 · RouteBadge 150. Lint baseline **0**.
- **Parked blocks are not dead code** — check for a parking comment or live `@modal` first. Un-park = `soon: false` + the page body.
- **Four bottom tabs — Home · Search · Pay · Me**; `/place` lights Home, `/visit` and `/reservation` light Me. Routes: `consumer-route-contract.ts` (mobile mirror same-PR).
- **Discover = `/discover`**, Home's rail: scroll · feed · chat · favs. `HomeDeckBoundary` fetches ONCE, coordless — Scroll re-fetches for Proximity. **Search is `/search`**: map + ONE bar. **Filters** on Feed + Scroll: Super Category · Scope · Google reviews · location. **Scroll** = one snapped card/screen, `tiwc`, 4 actions (Go stays); **Feed** = `CatalogRails`.
- **ONE section-nav look:** `grid-flow-col auto-cols-fr` on `w-max min-w-full`, scroller FALLBACK. Budget: Home's 4×(widest+28)+12 ≤ 359, Scroll widest → `text-xs`. Activity's scrolls — accepted. Re-measure before any pill change.
- **`(shell)/layout.tsx`'s `getUser()` IS the auth wall**, segment-wide; `PROTECTED_PREFIXES` = edge fast path. `route-structure.test.tsx` pins: every page under `(shell)`; every `@modal` intercept in `isModalContractPath` (**miss it → BLANK modal**) + hard twin; no dangling redirect; one tab lit.
- **Pay is a LABEL** (QR icon); `/new-visit` creates a visit, `/visit/{id}` IS one. Rename stops at the label, never routes/code/columns: object = ticket, column = `kind`. `/rewards*`, `/pay*`, `/qr`, `/ticket/:id` 308 forward. **`/visit/{id}` lights ME** via `BottomNav`'s `matchPrefixes`. `checkout` means Stripe.
- **Activity = THREE PAGES on Me**: `/me/notifications` · `/me/visits` · `/me/reservations`. `/inbox/*` 308s to `/me`; `/inbox/credits` → Pay's Wallet, listed ABOVE that catch-all. **Reservations = ONE feed**, upcoming then past; detail `/reservation/[id]`. Page bodies are FLEX COLUMNS (`MeScreen flush`) — a block parent collapses `EmptyState`.
- **Pay = container, TWO sections: QR · Wallet** (bare `/new-visit` = QR = default; Wallet = **Ways to pay · Cards · Credits**, three legacy paths 308 there). Card art = `place.photos[0]` under a scrim, ink when absent; bonus+expiry from `controls_config` (**5% · 90d**); **bought = spendable**. **No deck** — a plain list, spendable-first, expired sinks. Cards inline via `CardList`. No total; only in Top up. **QR lists the closest 50 places** (device location, Monterrey fallback): payable sorts first with a Pay-here chip, rest toast on tap. Header = `SearchBar` + ONE slot: the live-ticket row when `tickets.active`. `/me?cards=` 308s to Wallet (Stripe return). 2+ chars call `consumer-web-suggest-places`. One tap creates the ticket at `base`, opening **THE TICKET** at `/visit/[id]` — **SEVEN steps (v4): Bill · Reward · Task · QR · Pay · Validate · Results** (`ticket-journey.ts`). Hero panels: `TicketHero` (`rounded-panel`). Bill+tip guest-entered, **required on the QR**; tip rides pre-discount subtotal, uncapped. Staff approve (freezes it) or return ONE named fix. Sync = `consumer-web-get-ticket` 10s; rates = `consumer-web-get-discount-quote`.
- **Proofs are screenshots** → `ticket-proofs` bucket (RLS: own folder), URL persisted. Nothing reads it yet (Ojo, staged).
- **Classes — two axes, never merged.** `bronze ‹ silver ‹ gold ‹ diamond` earned/public; `free`/`premium` paid/private; LEGACY keys bridge `class-context`. **Passport prints neither Plan nor privacy** (`profile_public` defaults true; Settings owns it). The bar is a door; Instagram+Class live in header chips + Passport. **Me boxes are routes, never sheets** (`/me/passport|profile|class|instagram|plan|settings|help|notifications|visits|reservations`). Grid = seven pairs, no tail; Legal + version in Help, not Settings; no Cards cell (Wallet lists them), no More. Favs = localStorage.
- Edge Functions: `consumer-web-*`. CI: `web-consumer.yml` (lint · typecheck · test · build).
