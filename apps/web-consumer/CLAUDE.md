# apps/web-consumer — consumer app (consumer.mesita.ai)

> Monorepo-wide rules: root [`CLAUDE.md`](../../CLAUDE.md) (the quickstart) — read it first. This file adds only package-specific rules.

- **Light theme + semantic tokens only** (`bg-card`, `text-foreground`, `border-border`) — never `bg-zinc-900`/`text-white` on app surfaces. Consumer surfaces read **premium**: branded gradients, tinted icon circles, differentiated chips; wireframe stacks are a regression. Design map: Notion Product Rules §F.
- **Overlay & loading primitives are mandatory:** route modals via `SlideOverShell`/`BottomSheetShell` from the segment `layout.tsx` (never `page.tsx`); state overlays via `LocalSheet`/`LocalDialog` (never `fixed inset-0`); loading via `Spinner`/`Skeleton`. Z-scale: BottomNav 40 · @modal 120 · local 130 · Toaster 140. Lint baseline **0**.
- **Parked blocks are not dead code.** Look for a parking comment, a coming-soon route, or a live `@modal` before deleting. `CatalogGrid` works; un-parking Catalog is `soon: false` plus the page body.
- **Five bottom tabs — Home · Search · Visit · Inbox · Me**, plain labels. Canonical routes + legacy redirects: `src/lib/consumer-route-contract.ts`, drift-guarded against the mobile copy.
- **`(shell)/layout.tsx`'s `getUser()` IS the auth wall**, inherited segment-wide; `PROTECTED_PREFIXES` is only an edge fast path. `route-structure.test.tsx` guards the shape: every page under `(shell)`; every `@modal` intercept allowed by `isModalContractPath` (**miss it and the modal renders BLANK**) and owning a hard twin (interception is soft-nav only); no dangling redirect; one tab lit per surface.
- **The third tab is Visit** (QR icon) — never "Rewards", never "Pay": `checkout` means Stripe here. **`/new-visit`** creates one, **`/visit/{id}`** is one; `/rewards*`, `/pay*`, `/qr`, `/ticket/:id` 308 forward. **`/visit/{id}` lights INBOX** (its list lives there, like `/reservation/{id}`); `BottomNav` matches `matchPrefixes: string[]`. **The OBJECT is a ticket, the column is `kind`** — never cascade a URL rename into code or columns.
- **Inbox = one container, four sections, fixed order: Visits · Orders · Reservations · Notifications** (bare `/inbox` → visits). **The order is load-bearing**, pinned by a test. Icon is a tray, not a calendar. **Visits** reads the wallet's `useConsumerTickets`. **Orders** is parked: no table, EF or type. **Reservations** is ONE feed, upcoming soonest-first then past most-recent-first. **Notifications is YOUR activity only** — global lives at Home › Social. **Detail stays at `/reservation/[id]`**.
- **The wallet is a searchbar over a bare place list** — no tabs, no ticket lists, **no steps rail**; keep the "Your visits live in Inbox" link. Header = `search/SearchBar` (filter affordance optional); `place-list-filter` matches name · zone · category. One tap creates the ticket at `base` and opens **THE TICKET** at `/visit/[id]` (reward → task → QR → results); a place with a live ticket re-opens it. The rung is picked inside and re-prices upward. Rates come from `consumer-web-get-reward-quote`, never a static ladder.
- **Proofs are screenshots:** story and review submissions upload client-side to `ticket-proofs` (RLS: own folder) and persist the URL. The declaration verifies; nothing reads the image yet (Ojo, staged).
- **Home hub = five modes; only Swipe and Favorites are FUNCTIONAL.** Catalog · Chat · Social redirect to swipe; the pill opens a coming-soon dialog. All five pills stay visible and fit `max-w-md` at rest; `HomeModeNav` scrolls (`scrollbar-hide`) only as the large-text fallback. The AI mode is **`/home/chat`** (`/home/ai` 308s to it; the `?mode=` map holds a bare segment, so grep misses it). **Don Memo** is the persona inside it, Spanish-first — app chrome stays English.
- **Classes v2 — two axes, never merged.** `bronze ‹ silver ‹ gold ‹ diamond` earned/public; `free`/`premium` plan paid/private; LEGACY keys bridge in `class-context`. Me is flat (`/me`); Class + Settings are modals. Favorites = localStorage. Referral = `/share`.
- Edge Functions: `consumer-web-*`.
- CI: `web-consumer.yml` — lint · typecheck · test · build, all blocking (Node 22+), path-filtered.
