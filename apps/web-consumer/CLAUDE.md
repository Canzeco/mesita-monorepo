# apps/web-consumer — consumer app (consumer.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first — the quickstart; Notion holds the deep docs. Package-specific rules only below.

- **Light theme + semantic tokens only** (`bg-card`/`text-foreground`/`border-border`), never `bg-zinc-900`/`text-white`. Surfaces read **premium**; wireframe stacks = regression. Map: Notion Docs › Design.
- **Overlay & loading primitives are mandatory:** route modals = `SlideOverShell`/`BottomSheetShell` from the segment `layout.tsx`, never `page.tsx`; state overlays = `LocalSheet`/`LocalDialog`, never `fixed inset-0`; loading = `Spinner`/`Skeleton`. **ONE semi-modal: `SEMI_MODAL_PANEL_CLASS` (80%) on BOTH sheet shells** — never hardcode a panel height. **A confirm is a `LocalDialog`, not a short sheet.** Z: BottomNav 40 · @modal 120 · local 130 · Toaster 140 · RouteBadge 150. Lint baseline **0**.
- **Parked blocks are not dead code** — check for a parking comment or live `@modal` before deleting. Un-park = `soon: false` + the page body.
- **Four bottom tabs — Discover · Pay · Activity · Me**, plain labels; `/place` lights Discover. Routes: `consumer-route-contract.ts`. **Mobile mirror = SEPARATE PR.**
- **Discover = `/discover`, FIVE modes, ALL LIVE, segments match labels** (the exception): map · search · swipe · chat · favs. `HomeDeckBoundary` fetches the deck ONCE in the layout; Swipe/Chat/Favs read it from context, so switching never refetches. **Search** absorbed Name+Catalog+Social: name bar over `CatalogRails` idle, results when typing — never both. Default `/discover/map`; `/home*`/`/explore*`/`/search` 308 there in ONE hop (T4 caps 2).
- **ONE section-nav look:** `grid-flow-col auto-cols-fr` on `w-max min-w-full` — equal columns, scroller as FALLBACK. Discover 20%, Activity 25%, Pay 50%. Budgeted by the LONGEST label (+26px chrome): at 375px Discover's columns are 68.6px vs "Search" ~68; Activity's 86.8px vs "Reservations" ~96, so **that row scrolls on a phone — accepted**. Re-measure before adding a pill.
- **`(shell)/layout.tsx`'s `getUser()` IS the auth wall**, segment-wide; `PROTECTED_PREFIXES` = edge fast path only. `route-structure.test.tsx` pins: every page under `(shell)`; every `@modal` intercept in `isModalContractPath` (**miss it → BLANK modal**) + hard twin; no dangling redirect; one tab lit.
- **Third tab is LABELLED Pay** (QR icon); `/new-visit` creates a visit, `/visit/{id}` IS one. **A rename stops at the label** — never cascade into routes, code or columns: object = ticket, column = `kind`. `/rewards*`, `/pay*`, `/qr`, `/ticket/:id` 308 forward. **`/visit/{id}` lights ACTIVITY**; `BottomNav` matches `matchPrefixes: string[]`. `checkout` means Stripe.
- **Activity = one container, FOUR sections, fixed order: Alerts · Visits · Orders · Reservations** (bare `/inbox` → visits: **default ≠ first, deliberately**; **order load-bearing**, pinned). Only **Alerts** still differs from its route (`notifications`) — Bookings went back to Reservations. **Wallet LEFT for Pay** (Activity holds events, a wallet holds instruments); `/inbox/credits` 308s to `/new-visit/wallet`. **Visits** reads `useConsumerTickets`. **Orders** parked: no table/EF/type. **Reservations** = ONE feed, upcoming soonest-first then past newest-first. **Detail stays at `/reservation/[id]`**.
- **Pay = container, TWO sections: New · Wallet** (bare `/new-visit` is New and the default; Wallet = parked Credits emulator + LIVE cards sheet + parked Gift). **New lists the closest 50 places** (device location, Monterrey fallback) — no ticket rows, **no Open chip**, **no steps rail**. Header = `SearchBar` + ONE slot: live-ticket row when `tickets.active`, else the Activity link. Me keeps its cards door (`/me?cards=` is Stripe's return). 2+ chars call `consumer-web-suggest-places`. One tap creates the ticket at `base`, opening **THE TICKET** at `/visit/[id]` — **SEVEN steps (v4): Bill · Reward · Task · QR · Pay · Validate · Results** (`ticket-journey.ts`). Hero panels use `TicketHero` (`rounded-panel`), never a raw corner. Bill+tip guest-entered, **required on the QR**; tip rides the pre-discount subtotal, uncapped. Staff approve (freezes it) or send back ONE named fix. Live sync = `consumer-web-get-ticket` 10s; rates from `consumer-web-get-discount-quote`.
- **Proofs are screenshots** → `ticket-proofs` bucket (RLS: own folder), URL persisted. The declaration verifies; nothing reads it yet (Ojo, staged).
- **Classes v2 — two axes, never merged.** `bronze ‹ silver ‹ gold ‹ diamond` earned/public; `free`/`premium` paid/private; LEGACY keys bridge in `class-context`. Me is flat; Class + Settings modals. Favs = localStorage. Referral `/share`.
- Edge Functions: `consumer-web-*`. CI: `web-consumer.yml` (lint · typecheck · test · build).
