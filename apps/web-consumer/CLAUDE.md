# apps/web-consumer — consumer app (consumer.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first — the quickstart; Notion holds the deep docs. Package-specific rules only below.

- **Light theme + semantic tokens only** (`bg-card`/`text-foreground`/`border-border`), never `bg-zinc-900`/`text-white` — TWO carve-outs, bounded there: `BalanceCard`'s photo face, `CreditsClient`'s border-less rows. Surfaces read **premium**; wireframe stacks = regression. Map: Notion Docs › Design.
- **Overlay & loading primitives are mandatory:** route modals = `SlideOverShell`/`BottomSheetShell` from the segment `layout.tsx`, never `page.tsx`; state overlays = `LocalSheet`/`LocalDialog`, never `fixed inset-0`; loading = `Spinner`/`Skeleton`. **ONE semi-modal: `SEMI_MODAL_PANEL_CLASS` (80%) on BOTH sheet shells** — never hardcode a panel height. **A confirm is a `LocalDialog`, not a short sheet.** Z: BottomNav 40 · @modal 120 · local 130 · Toaster 140 · RouteBadge 150. Lint baseline **0**.
- **Parked blocks are not dead code** — check for a parking comment or live `@modal` first. Un-park = `soon: false` + the page body.
- **Four bottom tabs — Home · Search · Pay · Me**; `/place` lights Home, Activity's routes light Me. Routes: `consumer-route-contract.ts` (mobile mirror same-PR; `mobile-consumer` FROZEN).
- **Discover = `/discover`**, Home's rail alone now: swipe · catalog · chat · favs, in that order — Swipe leads and is default. `HomeDeckBoundary` fetches ONCE. **Search is `/search`**, its own route, no shared layout — map + the ONLY bar, results replace the rail. **Filters is a bottom-overlay pill**. **Catalog** = `CatalogRails`, no bar. Legacy paths 308 in ONE hop.
- **ONE section-nav look:** `grid-flow-col auto-cols-fr` on `w-max min-w-full`, scroller FALLBACK. Budget = longest label +26px: Home's 4×widest+16 ≤ 359, Catalog widest → `type-label`. Activity's scrolls — accepted. Re-measure before adding a pill.
- **`(shell)/layout.tsx`'s `getUser()` IS the auth wall**, segment-wide; `PROTECTED_PREFIXES` = edge fast path. `route-structure.test.tsx` pins: every page under `(shell)`; every `@modal` intercept in `isModalContractPath` (**miss it → BLANK modal**) + hard twin; no dangling redirect; one tab lit.
- **Pay is a LABEL** (QR icon); `/new-visit` creates a visit, `/visit/{id}` IS one. Rename stops at the label, never routes/code/columns: object = ticket, column = `kind`. `/rewards*`, `/pay*`, `/qr`, `/ticket/:id` 308 forward. **`/visit/{id}` lights ME** via `BottomNav`'s `matchPrefixes`. `checkout` means Stripe.
- **Activity = one container, THREE sections, fixed order: Alerts · Visits · Reservations** (bare `/inbox` → Visits: **default ≠ first, deliberately**; order pinned). Only **Alerts** differs from its route (`notifications`). **Visits** reads `useConsumerTickets`; Orders folded in, `/inbox/orders` 308s here. **Reservations** = ONE feed, upcoming soonest-first then past newest-first; detail `/reservation/[id]`. **Not a bottom tab** — from Me.
- **Pay = container, TWO sections: New · Wallet** (bare `/new-visit` = New = the default; Wallet = parked Credits deck + LIVE cards sheet, three legacy paths 308 there). Cards are `place.photos[0]` under a fixed scrim, ink face when absent; hold+bonus from `controls_config` (**3h**). **Deck is ONE state**; `PEEK_PX`/`CARD_PX` are MINIMUMS, spendable-first, painted in REVERSE (rank 1 = front). No total on the surface — only in Top up. **New lists the closest 50 places** (device location, Monterrey fallback): payable sorts first with a Pay-here chip, the rest toast on tap. Header = `SearchBar` + ONE slot: the live-ticket row when `tickets.active`. Me keeps its cards door (`/me?cards=` = Stripe's return). 2+ chars call `consumer-web-suggest-places`. One tap creates the ticket at `base`, opening **THE TICKET** at `/visit/[id]` — **SEVEN steps (v4): Bill · Reward · Task · QR · Pay · Validate · Results** (`ticket-journey.ts`). Hero panels use `TicketHero` (`rounded-panel`). Bill+tip guest-entered, **required on the QR**; tip rides the pre-discount subtotal, uncapped. Staff approve (freezes it) or send back ONE named fix. Sync = `consumer-web-get-ticket` 10s; rates = `consumer-web-get-discount-quote`.
- **Proofs are screenshots** → `ticket-proofs` bucket (RLS: own folder), URL persisted. Nothing reads it yet (Ojo, staged).
- **Classes — two axes, never merged.** `bronze ‹ silver ‹ gold ‹ diamond` earned/public; `free`/`premium` paid/private; LEGACY keys bridge `class-context`. **Passport prints Class + Instagram, never Plan** (card+sheet; its number row opens the sheet). Me = THREE ZONES: passport · `StatBand` (a COUNT) · `BoxGroup` (a DESTINATION); the split is MATERIAL. Instagram/Cards/AI behind More. Favs = localStorage.
- Edge Functions: `consumer-web-*`. CI: `web-consumer.yml` (lint · typecheck · test · build).
