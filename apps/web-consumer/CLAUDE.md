# apps/web-consumer — consumer app (consumer.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first — the quickstart; Notion holds the deep docs. Package-specific rules only below.

- **Light theme + semantic tokens only** (`bg-card`, `text-foreground`, `border-border`) — never `bg-zinc-900`/`text-white`. Surfaces read **premium**; wireframe stacks = regression. Design map: Notion Docs › Design.
- **Overlay & loading primitives are mandatory:** route modals = `SlideOverShell`/`BottomSheetShell` from the segment `layout.tsx` (never `page.tsx`); state overlays = `LocalSheet`/`LocalDialog` (never `fixed inset-0`); loading = `Spinner`/`Skeleton`. **ONE semi-modal: `SEMI_MODAL_PANEL_CLASS` (80% of the card) on BOTH sheet shells** — never hardcode a panel height. **A confirm is a `LocalDialog`, not a short sheet.** Z: BottomNav 40 · @modal 120 · local 130 · Toaster 140 · RouteBadge 150. Lint baseline **0**.
- **Parked blocks are not dead code** — look for a parking comment, a coming-soon route, or a live `@modal` before deleting. Un-parking = `soon: false` plus the page body.
- **Five bottom tabs — Home · Search · Pay · Inbox · Me**, plain labels. Routes + legacy redirects: `src/lib/consumer-route-contract.ts`, drift-guarded against mobile.
- **`(shell)/layout.tsx`'s `getUser()` IS the auth wall**, inherited segment-wide; `PROTECTED_PREFIXES` = edge fast path only. `route-structure.test.tsx` guards the shape: every page under `(shell)`; every `@modal` intercept in `isModalContractPath` (**miss it → BLANK modal**) with a hard twin; no dangling redirect; one tab lit per surface.
- **The third tab is LABELLED Pay** (QR icon); **`/new-visit`** creates one, **`/visit/{id}`** is one. **A rename stops at the label** — never cascade into routes, code or columns: object = ticket, column = `kind`, Inbox section = Visits. `/rewards*`, `/pay*`, `/qr`, `/ticket/:id` 308 forward. **`/visit/{id}` lights INBOX**; `BottomNav` matches `matchPrefixes: string[]`. `checkout` means Stripe.
- **Inbox = one container, four sections, fixed order: Visits · Orders · Reservations · Notifications** (bare `/inbox` → visits; **order load-bearing**, pinned by a test; tray icon). **Visits** reads `useConsumerTickets`. **Orders** parked: no table, EF or type. **Reservations** = ONE feed, upcoming soonest-first then past most-recent-first. **Notifications = YOUR activity** — global lives at Home › Social. **Detail stays at `/reservation/[id]`**.
- **Pay lists the closest 50 listed places** (device location, Monterrey fallback) — no tabs, no ticket rows, **no Open chip**, **no steps rail**. Keep the Inbox history link. Header = `search/SearchBar`; 2+ characters call `consumer-web-suggest-places`. One tap creates the ticket at `base` and opens **THE TICKET** at `/visit/[id]` — **SEVEN steps (v4): Bill · Reward · Task · QR · Pay · Validate · Results** (`lib/ticket-journey.ts`). Hero panels use `TicketHero` (`rounded-panel`); never a raw 18/24/28px corner. Bill+tip is guest-entered, **required on the QR**; tip rides the pre-discount subtotal, never capped. Staff approve (freezes the amount) or send back ONE named fix. Pay = at the place (Credits parked). Live sync = `consumer-web-get-ticket` at 10s. Rates from `consumer-web-get-discount-quote`.
- **Proofs are screenshots** → `ticket-proofs` bucket (RLS: own folder), URL persisted. The declaration verifies; nothing reads the image yet (Ojo, staged).
- **Home hub is Soon.** All five pills (Swipe · Catalog · Chat · Social · Favorites) open coming-soon; `/home/swipe` is the Soon empty state. Un-park is `soon:false` + restore bodies. The AI mode is **`/home/chat`** (`/home/ai` 308s; the `?mode=` map holds a bare segment — grep misses it). **Don Memo** is its persona. Search stays live.
- **Classes v2 — two axes, never merged.** `bronze ‹ silver ‹ gold ‹ diamond` earned/public; `free`/`premium` paid/private; LEGACY keys bridge in `class-context`. Me is flat; Class + Settings are modals. Favorites = localStorage. Referral = `/share`.
- Edge Functions: `consumer-web-*`. CI: `web-consumer.yml` (lint · typecheck · test · build).
