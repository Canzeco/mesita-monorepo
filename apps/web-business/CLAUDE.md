# apps/web-business — business console (business.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first. Package rules only.

- **Vercel** `mesita-web-business`, Root `apps/web-business`; `mesita-web-business-legacy` is a decoy. Light theme, semantic tokens. CI `web-business.yml`: lint · typecheck · test · build, path-filtered. Clients call `business-web-*` EFs.
- **Routes** (`lib/console-routes.ts`): **the address names its subject; ORG_PAGES = ORG_TARGETS = ORG_RAIL_TARGETS, ONE array.** `/places/<id>/{profile,menus,reviews,capabilities,rewards,admin}` · `/orgs/<id>/{configuration,products,places(/new),customers,activity}` · `/account` · `/orgs/new`. **Bare `/orgs/<id>` 307s** to `/configuration` and alone reads Stripe's `?connect=`, handing it to Products (mint with `orgRootHref`). Most names have a **flat** twin, ONE file `(shell)/[flat]`: 307 onto the canonical for remembered scope; nothing selected renders `NoPlaceYet`; unknown 404; none collides with a static dir. **`places` and `payments` have none.** The rail links CANONICAL. `/orgs/<id>/switch?to=` writes the org cookie, clears the place cookie. `/` is 307, never 308. **No `next.config.ts` rule shadows a live address.**
- **Nav:** LEFT RAIL, **no wordmark**, **THREE SECTIONS**: Account (a link, no subitems), **Organization** and **Place selectors**, each over its pages (Admin super-admin only); Collapse in footer. **ONE row shape** — a selector IS a row, ranked by colour not size; pages **indent one depth**, **hairline seams** between groups; no eyebrow; one pill, no id. **Ceremonies and metas live in the selector menus**, never a row; selectors guard first. At `w-16`, chips only. Rows never dim; **Soon lives on the PAGE**. `Sidebar.tsx` is DARK, `--sidebar-*` only. `AppShell.tsx` resolves scope into `RailScopeContext`; `main` alone scrolls.
- **One box, said once.** `shared/Section.tsx` IS the box: name in the heading, fact in the body, action in `right` — never a description repeating the title. **Configuration**: Members · Brand · Developers. **No door rows. Account is the person alone.** Never two badges for one fact.
- **Products is the catalogue**: `PartnerBanner`, eight cards, then Mesita Pay (account, seam, switch) for a partner. **A card states a fact the server READ** (`lib/products.ts`, pure, by test): Profile is always free; partner-gated read Locked, no verb; per-place print a count off `business-web-list-places`, and a FAILED read prints no number, never zero. Terminal is the one Soon.
- **Add place is a SEARCH**: one bar, one list; each row states its state and verb (Create · Claim · Open); another org's place gets none.
- **Capabilities and Rewards are ONE engine.** `PromosSection` takes a `zone`; `ZONE_ROWS` (`sections/controls/offerings.ts`) owns the split, by test.
- **Place heading, not a bar.** `PlaceHeading.tsx` is the `h1`. The rail learns pool places from `OpenPlace.tsx`, unsaved edits from `PlaceNavBridge.tsx`, the only `PlaceContext` reader.
- **Layout:** fluid, no max-width. `(shell)/layout.tsx` sets `SHELL_GUTTER`, rail outside; `SHELL_BLEED` is full-bleed. Pages: fragments with `loading.tsx`; forms cap at `FORM_COLUMN_CLASS`; save = `PlaceSaveBar`.
- **Never rebuild ticket UI**: Validate is staff-only; leave `business-web-*-ticket*`.
- `plan=pro` is Mesita Partner. **"Membership" banned.** Roles: owner/editor/viewer.
