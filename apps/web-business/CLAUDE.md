# apps/web-business — business console (business.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first. Package rules only below.

- **Deploys** via Vercel `mesita-web-business`, Root Directory `apps/web-business`; `mesita-web-business-legacy` is a decoy. Light theme, semantic tokens, high-density — don't ornament.
- **Routes** (`lib/console-routes.ts`): **the address names its subject, and no segment repeats its parent's noun.** Canonical `/places/<id>/{profile,reviews,capabilities,rewards,admin}` · `/orgs/<id>` and `/orgs/<id>/{payments,credits,activity,members,places(/new)}` · `/account` · `/orgs/new`. Each has a **flat** twin (`/profile`, `/credits`, …), all ten served by ONE file `(shell)/[flat]` over `lib/flat-address.tsx`: 307 onto the canonical address for the remembered place/org (`lib/selected-place.ts`, two cookies); nothing selected renders `NoPlaceYet`; an unclaimed name 404s. **No flat name may collide with a static directory** (static wins; a test asserts both ways). The rail links CANONICAL. `/orgs/<id>/switch?to=<flat>` is the switcher's forwarder (writes the org cookie, clears the place cookie) and the only route handler here; Stripe's stored `/orgs/<id>?connect=` hits the page, which redirects onto Payments. `/` resolves 307, never 308. **No `next.config.ts` rule may shadow a live address**; `legacy-redirects.test.ts` walks every address, canonical and flat, through that table.
- **Nav:** LEFT RAIL, **no wordmark**, **two named groups** — the organization's four rows, then the place's five (Admin super-admin only) — each headed by its subject's NAME, falling back to the noun. Account + Collapse are ONE footer pinned to the bottom. **Nothing indents** — the header carries the grouping. No switcher, Plus, chip, box, tree line or `role="group"`; one seam, one pill, no visible id. Members and Places have no row and light Organization. With no place the place rows stay at full strength, never dimmed. Mobile topbar: the scope (`org · place`), not a logo. `AppShell.tsx` (`fixed inset-0` + `overflow-clip`) resolves scope once into `RailScopeContext`; `main` is the only scroller; one breakpoint `lg`. `Sidebar.tsx` is DARK: `--sidebar-*` dock tokens, never a page token; `w-60`/`w-16`. Every page has `loading.tsx`.
- **Capabilities and Rewards are ONE engine, two displays.** `PromosSection` takes a `zone`; `ZONE_ROWS` (`sections/controls/offerings.ts`) owns the split, proven total by test. Never fork the ladder — its rungs depend on one another.
- **Never rebuild ticket UI**: Mesita Validate is the staff surface; leave `business-web-*-ticket*` alone.
- **Place heading, not a bar.** `PlaceHeading.tsx` is the `h1`. The rail learns a pool place from `OpenPlace.tsx`, unsaved edits from `PlaceNavBridge.tsx` — the only console component that may read `PlaceContext`.
- **Layout:** fluid, no max-width. `(shell)/layout.tsx` sets `SHELL_GUTTER`; the rail sits outside. Full-bleed uses `SHELL_BLEED`. `PlaceStatesTable` never sets `w-full`. Pages return a fragment. Forms cap at `FORM_COLUMN_CLASS`. Save = `PlaceSaveBar`.
- Plan SKUs: **Free** + **Verified** (`plan=pro`). Partnership is free. **"Membership" banned.** Roles: `owner`/`editor`/`viewer`.
- Clients never call the DB — `business-web-*` Edge Functions.
- CI: `web-business.yml` — lint · typecheck · test · build (Node 22+), path-filtered.
