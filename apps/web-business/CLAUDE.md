# apps/web-business — business console (business.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first — the quickstart; Notion holds the deep docs. Package-specific rules only below.

- **Deploys via the Vercel `mesita-web-business` project**, Root Directory `apps/web-business`. `mesita-web-business-legacy` is a decoy; a wrong connection = silent no-deploy.
- Light theme + semantic tokens. Business surfaces stay **calm and high-density** — don't ornament them.
- **Four screens:** Account · Organization · Places · Place (`SHELL_ROUTES` in `lib/console-routes.ts`). **Org Places is a rail break; Public Places is neither** — both are `?owned=` filters on one merged list. `/places/<id>` is the ONE place console, four views — **Profile · Capabilities · Activity · Admin**; Admin is super-admin only and every box on it calls `admin-web-*`. `next.config.ts` redirects legacy URLs here. **Never rebuild console ticket UI**: Mesita Validate (`apps/web-validate`) is the whole staff ticket surface — leave the `business-web-*-ticket*` EFs alone.
- **Nav is a LEFT RAIL, and it is FLAT.** `AppShell.tsx` pins the frame (`fixed inset-0` + `overflow-clip`); `main` is the ONLY scroller; **one breakpoint, `lg`** (rail above, drawer below). `Sidebar.tsx`: light `--sidebar` tokens, never admin's inversion; `w-60` ↔ `w-16`, cookie-persisted; every text token a semantic pair, never an opacity fraction. **Every row at ONE indent** — no tree lines, no bullet dots, no `depth`. Group with `SectionBreak` (hairline + `TINY_LABEL_CLASS`). Rows: Organization, its places under an `Org Places` break, All Places; the open place is its own section rendering `visibleTabs()` (**1 to 4**, never a disabled one); Account pinned. `ConsoleHeader.tsx` carries the breadcrumb + route readout the chromeless window needs.
- **The place screen has a heading, not a bar.** `PlaceHeading.tsx` is its one `h1`, in the content flow, `font-sans`. The rail learns the place's name and view set from `OpenPlace.tsx`, and the unsaved-edits guard from `PlaceNavBridge.tsx` — the ONLY console component that may read `PlaceContext`. **Values travel up; consumers never move down.**
- **Layout:** the shell owns the container and it is FLUID, no max-width — `(shell)/layout.tsx` sets the gutter once (`SHELL_GUTTER`), the rail sits outside it. A full-bleed child cancels it with `SHELL_BLEED`, its exact negative. `PlaceStatesTable` is the last breakout and must never set `w-full`. Pages return a bare fragment and never set their own width. Section cards are `Section.tsx`; forms cap at `FORM_COLUMN_CLASS` — cap the form, not the card. Global save = the floating `PlaceSaveBar`.
- Nomenclature: businesses subscribe to a **plan**; sold SKUs are **Free** + **Verified** (`plan=pro`), and joining Partnership is free. **"Membership" is banned in copy** — what a place joins is **Partnership**. Member roles: `owner`/`editor`/`viewer`.
- Clients never call the DB — everything via `business-web-*` Edge Functions.
- CI: `web-business.yml` — lint · typecheck · test · build, all blocking (Node 22+), path-filtered to `apps/web-business/**`.
