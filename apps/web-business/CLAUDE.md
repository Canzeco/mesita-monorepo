# apps/web-business — business console (business.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first — the quickstart; Notion holds the deep docs. Package-specific rules only below.

- **Deploys via the Vercel `mesita-web-business` project**, pointed at `Canzeco/mesita-monorepo` with Root Directory `apps/web-business` (cutover landed 2026-07-11). The frozen standalone repos — especially `mesita-web-business-legacy` — are decoys; a wrong connection = silent no-deploy.
- Light theme + semantic tokens. Business surfaces stay **calm and high-density** — don't ornament them.
- **ONE place console** (MESITA-1564): `/places/<id>` in the `(shell)` route group, four tabs — **Profile · Capabilities · Activity · Admin** (`PlaceTabs.tsx`). Admin renders for super-admins only; every box on it calls `admin-web-*`. The screens are Account · Organization · Org Places · Public Places · Place (`SHELL_ROUTES` in `lib/console-routes.ts`, and a test asserts each maps to a route file). The old `(console)` tree — `/place/<id>` under Profile · Partnership · Performance · Settings — is **deleted**; `next.config.ts` redirects every legacy URL to `/places/<id>`, and a contract test proves none 404s. **Never rebuild console ticket UI**: Mesita Validate (`apps/web-validate`, host `check.mesita.ai` until MESITA-1116) is the whole staff ticket surface. The leftover `business-web-{list,cancel,mark-paid,submit-bill}-ticket*` EFs still exist; leave them alone.
- **Layout convention:** the shell owns the container — `(shell)/layout.tsx` sets it once and `TopNav` matches it, so the title shares the cards' left edge. Pages return a bare fragment and inherit `flex flex-col gap-4`; they never set their own width. Section cards are `Section.tsx`; forms cap at `FORM_COLUMN_CLASS` (`lib/ui-classes.ts`) — cap the form, not the card. The ported `place-manage` sections are a masonry (`columns-1 lg:columns-2`), not a grid. Global save = the floating `PlaceSaveBar`.
- Nomenclature: businesses subscribe to a **plan**. Sold SKUs in the console are **Free** + **Verified** (`plan=pro`, yearly Partnership subscription — Promos v4 / MESITA-541). **"Membership" is banned in copy** — what a place buys is the **Partnership subscription**. Enum/DB still has `ultra` (and Notion pricing history may list Free/Pro/Ultra); the console folds Ultra onto Verified — "Promote" is retired. Per-project member roles: `owner`/`editor`/`viewer`.
- Clients never call the DB — everything via `business-web-*` Edge Functions.
- CI: `web-business.yml` — lint · typecheck · build, all blocking (Node 22+), path-filtered to `apps/web-business/**`.
