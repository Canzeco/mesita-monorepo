# apps/web-business — business console (business.mesita.ai)

> Read root [`CLAUDE.md`](../../CLAUDE.md) first — the quickstart; Notion holds the deep docs. Package-specific rules only below.

- **Deploys via the Vercel `mesita-web-business` project**, Root Directory `apps/web-business`. `mesita-web-business-legacy` is a decoy; a wrong connection = silent no-deploy.
- Light theme + semantic tokens. Business surfaces stay **calm and high-density** — don't ornament them.
- **Routes** (`lib/console-routes.ts`; the organization is in the PATH, never `?org=`): `/` resolves to your last place → org → Create · `/account` · `/orgs/new` · `/orgs/<id>` ONE page (Stripe · Partner · Members · Places; never subpages) · `/places` (ONE merged list; `?owned=` filters, never rows) · `/places/new` (claim, never mint) · `/places/<id>/<view>` — five views **Profile · Reviews · Activity · Capabilities · Admin**; Admin is super-admin only and every box on it calls `admin-web-*`. `orgs/[orgId]/layout.tsx` is the one membership check: foreign and missing ids 404. `next.config.ts` forwards old `?org=` addresses. **Never rebuild console ticket UI**: Mesita Validate (`apps/web-validate`) is the whole staff ticket surface — leave the `business-web-*-ticket*` EFs alone.
- **Nav is a LEFT RAIL of three scoped boxes:** Account · Organization (picker + Organization · Places) · Place (picker + the views). `AppShell.tsx` pins the frame (`fixed inset-0` + `overflow-clip`) and resolves the scope ONCE off the pathname (`lib/rail-scope.ts`); `main` is the ONLY scroller; **one breakpoint, `lg`**. `Sidebar.tsx`: light `--sidebar` tokens, `w-60` ↔ `w-16`, a box is a ground never a border, **zero indents**, exactly one ink pill, pickers never take it. Every page has `loading.tsx`. `ConsoleHeader.tsx`: crumb + route readout.
- **The place screen has a heading, not a bar.** `PlaceHeading.tsx` is its one `h1`, in the content flow, `font-sans`. The rail learns a pool place's name and view set from `OpenPlace.tsx`, and the unsaved-edits guard from `PlaceNavBridge.tsx` — the ONLY console component that may read `PlaceContext`. **Values travel up; consumers never move down.**
- **Layout:** the shell owns the container and it is FLUID, no max-width — `(shell)/layout.tsx` sets the gutter once (`SHELL_GUTTER`), the rail sits outside it. A full-bleed child cancels it with `SHELL_BLEED`, its exact negative. `PlaceStatesTable` is the last breakout and must never set `w-full`. Pages return a bare fragment and never set their own width. Section cards are `Section.tsx`; forms cap at `FORM_COLUMN_CLASS` — cap the form, not the card. Global save = the floating `PlaceSaveBar`.
- Nomenclature: businesses subscribe to a **plan**; sold SKUs are **Free** + **Verified** (`plan=pro`), and joining Partnership is free. **"Membership" is banned in copy** — what a place joins is **Partnership**. Member roles: `owner`/`editor`/`viewer`.
- Clients never call the DB — everything via `business-web-*` Edge Functions.
- CI: `web-business.yml` — lint · typecheck · test · build, all blocking (Node 22+), path-filtered to `apps/web-business/**`.
